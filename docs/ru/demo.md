# Демо

Рабочий экземпляр редактора с примером многостраничного сайта. Переключайте
страницы в панели **Pages**, добавляйте блоки из левой панели, выбирайте элемент
для редактирования стилей и попробуйте панели Variables и Settings. Изменения
остаются внутри фрейма и сбрасываются после перезагрузки.
