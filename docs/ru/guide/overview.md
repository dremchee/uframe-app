# Обзор

uframe — это **движок встраиваемого блочного редактора страниц**. Добавьте его
в своё приложение, чтобы пользователи собирали страницы на визуальном холсте,
настраивали стили и сохраняли результат как JSON или HTML. Это строительный
блок вашего продукта, а не готовый конструктор сайтов.

## Для кого

- **Продуктовые команды, которым нужен встроенный редактор страниц или
  контента.** SaaS-приложения, CMS, инструменты для лендингов — везде, где
  пользователям нужно собирать страницы из блоков без тяжёлого редактора в
  бандле и конфликтов CSS. Используйте [embed-клиент](/guide/embedding): редактор
  работает в iframe, а хост может быть написан на React, Svelte или обычном
  HTML.
- **Команды на Vue, которым нужен расширяемый редактор.** Хотите добавить свои
  блоки, плагины, кнопки тулбара или панели? Импортируйте
  [`<PageEditor>` напрямую](/guide/extending). Плагин — это обычный объект, который
  экспортирует npm-пакет.
- **Платформы и агентства с white-label-редактированием.** Интерфейс редактора
  переоформляется через [токены темы `uf-*`](/guide/theming) и остаётся изолированным
  в iframe, поэтому его можно отдавать своим клиентам как часть продукта.

## Что можно создать

- Дать нетехническим пользователям возможность **собирать страницы из блоков**:
  лендинги, контентные секции, формы. Встроены структурные, типографические,
  медийные блоки и блоки форм.
- Предложить **визуальное редактирование без кода**: flex/grid с drag handles,
  отступы, тени и фильтры, адаптивные брейкпоинты и CSS-переменные документа.
- Переиспользовать дизайн через символы (компоненты) с вариантами.
- Хранить **данные в своём формате**: документ — это JSON, проверяемый Zod, с
  экспортом HTML; способ хранения определяет ваше приложение.
- Публиковать результат в любом фронтенде: рендерить сохранённый документ в
  HTML или Vue-компоненты на сервере, статически или в браузере.

## Чем uframe не является

- **Это не хостинговый конструктор сайтов.** В нём нет бэкенда, деплоя и
  авторизации: uframe — встраиваемый движок редактора, а не сервис вроде Tilda
  или Webflow.
- **В основе — Vue.** Хост может быть любым благодаря embed-клиенту, но
  пользовательские блоки пишутся как Vue-компоненты.
- **Проект на ранней стадии.** Библиотека ещё не достигла 1.0 и API может
  меняться.

## Два способа интеграции

| | Embed-клиент | Vue-компонент |
| --- | --- | --- |
| Импорт | `@dremchee/uframe/embed` | `@dremchee/uframe` (`<PageEditor>`) |
| Стек хоста | Любой (iframe + postMessage) | Vue |
| Влияние на бандл | Минимальное — DOM + postMessage | Подключает Vue |
| Изоляция | Полная (iframe sandbox) | Внутри приложения |
| Расширение (свои блоки/плагины/панели) | — | ✓ |

uframe ориентирован прежде всего на iframe-встраивание, но поддерживает и
прямое использование во Vue. Начните с [локализации](./localization), чтобы
настроить язык интерфейса.
