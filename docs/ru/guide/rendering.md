# Рендеринг страниц

Документ uframe — переносимый JSON. Перед публикацией его нужно разрешить:
объединить общие настройки, раскрыть символы, подставить данные в привязки и
затем отрендерить HTML или Vue-дерево.

## Конвейер

Используйте `resolveDocument` из `@dremchee/uframe/core`, передавая документ,
общие настройки и данные. После разрешения используйте `renderDocumentToHtml`
для строки HTML или `renderDocumentToFragment` для Vue-рендеринга.

```ts
import { renderDocumentToHtml, resolveDocument } from '@dremchee/uframe/core'

const resolved = resolveDocument(document, { globals, dataContext })
const html = renderDocumentToHtml(resolved)
```

## Два способа рендеринга

- **HTML-строка** подходит для SSR, SSG, email-подобных экспортов и API.
- **Рекурсивные Vue-компоненты** подходят, когда типы блоков нужно
  переопределять интерактивными компонентами во фронтенде.

В обоих случаях подключите базовые стили страницы из
`@dremchee/uframe/styles/page-frame`, иначе не будут доступны ожидаемые
переменные и базовая раскладка блоков.

## Динамические данные и безопасность

Передавайте данные через `dataContext`; блоки `data-list` и `data-item`
используют их для повторения и контекста элементов. Данные получают на сервере
или в приложении-хосте, а не в редакторе.

Контент, созданный доверенными авторами, можно рендерить обычным путём. Для
документов от непроверенных авторов включайте `untrustedEmbeds`: embed-блоки
будут выполняться в sandboxed iframe, а не вставляться в страницу напрямую.

## Кэширование и производительность

Кэшируйте разрешённый результат по версии документа, данным и общим настройкам.
На сервере кэшируйте полученные данные рядом с HTML; в клиенте не разрешайте
документ повторно без изменения его входных данных. Не кэшируйте результат,
если он содержит персональные или авторизационные данные.
